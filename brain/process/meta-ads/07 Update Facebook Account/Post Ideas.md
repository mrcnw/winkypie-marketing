# Post Ideas — the ten educational statics, ranked

The queue for the Education slot in [[Posts Calendar]]. Ten topics, ranked on two axes:
**evidence** that the topic is asked about, and **distance to the product** — a post that
teaches something we then solve is worth two that teach something we don't.

Built 2026-09-08 from three inputs: the 28 static posts on `@roast.dating` walked live, the
ROAST blog index, and the search demand behind each topic. The format each one ships in is
[[Static Post Format]]. Guardrails are the root `CLAUDE.md` list; every number named below
must arrive with the `PRODUCT.md` §8 label attached or it does not ship.

**One caution before the table.** Roast's own statics pull 2–41 likes against 8,655 followers,
so their grid tells us which topics they *bet* on, not which ones won. Where a row's evidence
is only "they run it", that is what it says.

## Dropped, and why

Recorded so they stop coming back — the same discipline as [[Hooks And Angles]].

| Candidate | Why not |
|---|---|
| *7 signs she's into you* · *Why women ignore nice guys* · *Why she left and why she'll be back* | Roast's biggest static category and completely off-product. It is dating-coach content; we sell a photo. It would win followers we cannot convert |
| *Best Tinder bios for guys* · opener scripts | Explicit non-claims (`PRODUCT.md` §3): not a bio writer, not an opener writer. Teaching it invites the wrong install |
| *You're not ugly. You're unoptimized.* | Second-person appearance — Meta personal attributes, and body insecurity is an emotion we do not use (§9) |
| Anything with a user count, a rating or a testimonial | Guardrail 2. No ratings exist yet (`PRODUCT.md` §13) |
| *Shadowbanned? Probably not.* and other algorithm explainers | We have no data on any dating app's ranking. Repeating what a blog says about Tinder's algorithm is an unsourced claim wearing a lab coat |

## Order

([[Posts Calendar]]). Post 1 is written: `posts/WP_IG_EDU1_firstphoto.md`. Nothing below it
gets written until the one above it has posted — a queue of ten drafts nobody has run is the
failure mode the process README calls out.
