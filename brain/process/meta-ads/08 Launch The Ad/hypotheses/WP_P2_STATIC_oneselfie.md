## Rewritten 2026-09-22, and why

The first draft predicted a margin against [[WP_P2_PORTFOLIO_oneselfie]] — campaign 7, the
22-second wall this card compresses. **Campaign 7 has a brief and no render**, so that
comparison cannot be run and the prediction could never have been settled. Caught before the
file was dated, which is the only reason it cost nothing.

The variable moves with it. Instead of *wall against still*, this now tests **grid against
text-led card** — `oneselfie` beside [[WP_P2_STATIC_checkcard]] and
[[WP_P2_STATIC_firstchance]] in the same round. That is a question the swipe file genuinely
cannot answer: the niche's proven statics are all text-led cards, and nothing in it runs a
gallery. If campaign 7 is ever produced, the original wall-against-still comparison comes back
as its own hypothesis.

[[KPI]] is explicit that round one has no baseline, so this predicts a ranking inside the set
rather than a number.

## What would falsify it

Bottom two on link CTR at the impression floor. That would say the swipe file was right about
this niche — the proof has to be argued, not merely displayed — and the gallery shape is
retired rather than iterated.
