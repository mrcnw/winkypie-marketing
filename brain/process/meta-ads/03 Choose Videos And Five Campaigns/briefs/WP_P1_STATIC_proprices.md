# Brief — WP_P1_STATIC_proprices

cost — against the decision-moment static (campaign 1). Same persona-class static format,
different hook: that isolates the angle.

**Evidence:** Aragon's price-led headshot ads have run 95+ days; the persona's stated
alternative is a $200–900 session ([[Competitor Landscape]], adjacent competition). We
still show **no dollar figures** of any kind on the creative — ours or theirs (§11.6 for
ours; an unsourced range would break the citation rule for theirs).
