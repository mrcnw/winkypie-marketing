# Lifecycle & Push

Acquisition is only half the CAC equation — trial->paid conversion is the other half, and it's cheaper to fix.

## Key moments
| Moment | Message | Channel | Status |
|---|---|---|---|
| Install, no first shot | "Pick a pose. 30 seconds." | push | |
| First shot generated | celebrate + prompt second | in-app | |
| Trial day 1 | show what they made | push | |
| Trial ending -2d | honest reminder + cancellation path | push + email | |
| Trial expired, no convert | one win-back | push | |
| Churned subscriber | new poses released | push | |

## Rules
- Free trial reminders must include the cancellation path -> [[Brand Guardrails]]
- Push permission ask comes **after** the first successful Winky Shot, never on launch

## Metrics
Trial->paid is the number this channel owns. -> [[KPI]]
