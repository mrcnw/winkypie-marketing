# Apple Search Ads

Highest-intent paid channel for an iOS app, and immune to ATT signal loss (Apple owns the attribution).

## Structure
| Campaign type | Purpose |
|---|---|
| Brand | defend "winkypie" from competitor bids |
| Category | `ai photos`, `dating photos`, `ai headshot` |
| Competitor | competitor brand names |
| Discovery | broad match + search match, mines new keywords |

## Flow
Discovery finds keywords -> promote winners to exact-match Category -> add losers as negatives.
