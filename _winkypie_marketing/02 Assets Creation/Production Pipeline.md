# Production Pipeline

```
Angle (Messaging Matrix)
  -> Brief        (_Templates/Creative Brief)
  -> Script       (hook / demo / proof / CTA)
  -> Produce      (screen rec, render, UGC, static)
  -> Edit         (captions, 9:16 + 1:1 + 4:5)
  -> QA           (checklist below)
  -> Name         (Creative Naming)
  -> Ship         (Meta Ads -> Tracker)
  -> Log          (Experiment Log)
```

## Stages
| Stage | Owner | Output | Location |
|---|---|---|---|
| Brief | strategy | 1 page | `02 Assets Creation/Briefs/` |
| Script | copy | hook + beats | in brief |
| Produce | production | raw footage / renders | `02 Assets Creation/Raw/` |
| Edit | editor | master + cutdowns | `_Attachments/` |
| QA | strategy | pass/fail | checklist |
| Ship | media buyer | live ad | [[Tracker]] |

## QA checklist — every creative
- [ ] Hook lands in the first 1.5s (visual + text, no logo-first intro)
- [ ] Readable with sound off (burned-in captions)
- [ ] Safe zones respected for Reels/Stories (top 14% / bottom 20%)
- [ ] 9:16 primary, 1:1 and 4:5 cutdowns exported
- [ ] Only men shown
- [ ] AI disclosure present where a result is shown
- [ ] No unsourced stat -> checked against [[Claims & Proof]]
- [ ] No fabricated social proof
- [ ] Gradient is the single brand gradient
- [ ] Locked copy quoted exactly, not paraphrased
- [ ] Named per [[Creative Naming]]
- [ ] Logged in [[Tracker]] with the angle it tests

## Batch cadence
Ship **one batch per week**: 3 new hooks x 1 winning body, or 1 new body x 3 proven hooks. Never change both at once. -> [[Creative Testing Protocol]]
