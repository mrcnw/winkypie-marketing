# Glossary

| Term | Meaning |
|---|---|
| **AEM** | Aggregated Event Measurement - Meta's post-ATT event system |
| **ATT** | App Tracking Transparency - Apple's opt-in prompt |
| **SKAN** | SKAdNetwork - Apple's privacy-preserving attribution |
| **CPP** | Custom Product Page - alternate App Store page per campaign |
| **MMP** | Mobile Measurement Partner (AppsFlyer, Adjust, Singular) |
| **Hook rate** | 3s video plays / impressions |
| **Hold rate** | ThruPlays / 3s plays |
| **CPT** | Cost per trial start |
| **CBO** | Campaign Budget Optimization |
| **Learning phase** | Meta needs ~50 events/week per ad set to stabilise |
| **Winky Shot** | One generated photo. Trial includes 3. |
| **Whitelisting** | Running ads from a creator's own handle |
